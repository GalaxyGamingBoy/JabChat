# XMPP Standards Compliance
This is a complete list of the current standards that are supported by JabChat as an XMPP client as well as the implemented standards version.

| Identifier                                             | Version   | Summary                                                                                        |
|--------------------------------------------------------|-----------|------------------------------------------------------------------------------------------------|
| [RFC6129](https://xmpp.org/rfcs/rfc6120.html)          | Published    | Extensible Messaging and Presence Protocol (XMPP): Core                                        |
| [RFC7590](https://www.rfc-editor.org/rfc/rfc7590.html) | Published | Use of Transport Layer Security (TLS) in the Extensible Messaging and Presence Protocol (XMPP) |
| [RFC6121](https://xmpp.org/rfcs/rfc6121.html)          | Published | Extensible Messaging and Presence Protocol (XMPP): Instant Messaging and Presence              |
| [XEP0201](https://xmpp.org/extensions/xep-0201.html)   | 1.0       | Best Practices for Message Threads                                                             |
